# Motel Scala

Landing page modular gerada pelo Tapir LP a partir do site oficial [motelscala.com.br](https://www.motelscala.com.br/index).

## Estrutura

```
hotels/motel-scala/
├── README.md
├── images/
│   ├── logo.svg
│   ├── hero.jpg
│   ├── rooms/
│   ├── gallery/
│   ├── gastronomy/
│   └── decorations/
└── _scrape/          # HTML bruto (dev)
```

## Config

`configs/motel-scala.json`

## Comandos

```bash
# Dev
npm run dev:scala

# Build (gera dist/motel-scala/index.html)
npm run build -- motel-scala
```
